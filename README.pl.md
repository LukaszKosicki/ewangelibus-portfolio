# EwangeliBus – próbki kodu

Stworzony przeze mnie projekt Ewangelibus, który cały czas jest rozwijany. System obsługuje tysiące wiadomości e-mail przesłanych za pomocą formularza. Postawiony na VPS z k3s. Na osobnym serwerze znajduje się uruchomiony przeze mnie serwer e-mail. Technologie: Next.js, panel administracyjny w React i API w ASP.NET Core z PostgreSQL. Pełnego kodu nie publikuję, więc wrzucam wybrane fragmenty.

- [backend-samples](./backend-samples) – fragmenty API w .NET
- [frontend-samples](./frontend-samples) – fragmenty strony w Next.js
- [contact-form-nextjs](./contact-form-nextjs) – mały, uruchamialny przykład formularza kontaktowego

Pliki w `backend-samples` i `frontend-samples` są skopiowane z projektu bez zmian, dlatego nie da się ich uruchomić osobno. Przykład `contact-form-nextjs` to uproszczona wersja formularza ze strony, przygotowana z pomocą AI.
