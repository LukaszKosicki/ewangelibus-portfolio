# EwangeliBus – code samples

EwangeliBus is a project I built myself and still develop. The site has handled thousands of messages sent through its contact forms. It runs on a VPS with k3s, and the mail server is a separate one that I set up and run myself.

Stack: Next.js, an admin panel in React, and an ASP.NET Core API with PostgreSQL.

I am not publishing the full source, so here are selected parts:

- [backend-samples](./backend-samples) – excerpts from the .NET API
- [frontend-samples](./frontend-samples) – excerpts from the Next.js site
- [contact-form-nextjs](./contact-form-nextjs) – a small, runnable example of the contact form

The files in `backend-samples` and `frontend-samples` are copied from the project without changes, so they cannot be run on their own. `contact-form-nextjs` is a simplified version of the site's form, prepared with the help of AI.
